## First Concepts

### 1. What is Cybersecurity?

Cybersecurity is the practice of protecting computers,
networks, and data from digital attacks.

### 2. What is an Operating System?

An Operating System is system software that manages a computer's hardware and software and allows users to interact with the computer.

### 3. What is an IP Address?

An IP address (Internet Protocol address) is a numerical address assigned to a device on a network so that it can be identified and data can be sent to and from it.

### 4. HTTP vs HTTPS

HTTP stands for Hypertext Transfer Protocol. HTTPS stands for Hypertext Transfer Protocol Secure.
Both are protocols used to transfer information between a web browser and a website. The main difference is that HTTPS encrypts the connection, helping protect information while it travels between your browser and the website.
